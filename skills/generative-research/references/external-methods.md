# 可复用研究方法

这些方法按任务使用，补充主正文的四项能力；不构成每次必走的阶段。执行以本文件及现有参考文件为准，不要求访问、安装或运行来源项目。记录字段见 [记录与表达](records-and-views.md)，委派见 [执行与合并](execution.md)。

## 文献发现、筛选与全文获取

适用于论文检索、领域覆盖、文献综述和取证；正式综述展开筛选计数，窄问题保留足以复核的记录。

1. 根据问题明确范围和相关性标准，生成术语、同义词及适用文献类型，选择互补入口。文献索引、出版社和引用链用于发现；开放全文库用于补充发现与获取，不能单独代表整个领域。免费、收费及访问状态未知的相关论文均可进入候选。
2. 记录实际入口、检索式、日期、过滤条件、已浏览或导出范围、分页／数量限制和获取失败。检查工具默认过滤；开放获取字段可作为注释，按该字段筛掉不可免费读的论文会缩小发现范围。下载链接、免费全文、PDF 可得及单一预印本库不能成为默认发现条件。
3. 按标题／摘要筛相关性，再按原文处理需要全文才能判断的条件；缺少摘要或全文时标为待判断。关联同一研究的版本与多份报告，保留独立研究单位。按本题范围记录纳入、归并、排除、暂缓或待核原因，不能以“收费”或“打不开”替代相关性筛选。
4. 需要深读时寻找出版社页面、作者公开版本、机构库或现有授权订阅入口；核对版本与内容差异。获取失败的记录仍留在研究清单中，注明已有元数据／摘要、未获得全文、尝试过的途径及受影响的判断。实际付费使用依本次授权处理。
5. 正式综述分别记录发现数、去重、筛选及全文获取结果；全文未获取与因范围不符而排除分开统计，不补造缺失数量。阶段结果说明覆盖边界及尚未取回的相关研究；不能把已取得全文子集当成完整领域。探索或资源受限时先交付候选地图与明确缺口。

准备固定主要检索策略时，用已知符合范围的报告预检：记录各入口实际召回与漏检，查明术语、索引覆盖、过滤或分页等原因，再调整检索式。已知报告可来自用户种子或初步发现；预检集及其来源写明，通过预检不等于覆盖穷尽。

正式系统综述的最终全文资格判断应有独立初判与分歧处理：保留各审阅者的去向、理由及裁决，说明实际人员或 AI、材料、是否独立和单人限制。多个 agents 的一致意见不能自动等同于正式人类双审阅。探索性调研不默认增加这一流程。

发现顺序由相关性及覆盖价值决定；深读顺序可优先选择关键判断、重要反例与可获得材料，但保留未读候选。只有摘要时可以陈述“摘要报告了什么”，不能补写未见的方法、对照、指标细节或声称已核对全文。论文的收费状态不代表其质量，数据库或服务可免费使用也不意味着它只收录免费论文。

## 按主张评价研究质量

适用于比较性能、机制与因果解释，或准备据论文选择路线。先确定论文实际支持的主张，再按研究类型选择检查项；不为每篇材料套同一评分表。

| 检查 | 需要回答的问题 |
|---|---|
| 设计与对照 | 实验能否区分声称的机制与竞争解释？基线、对照和同时改变的变量怎样影响归因？ |
| 独立单位与划分 | 样本单位是人、装置、试次还是片段？训练／测试是否按实际使用条件隔离，是否存在泄露或伪重复？ |
| 测量与指标 | 标签、参考真值和标定是什么？指标是否回答目标，单位、聚合方式与比较条件是否一致？ |
| 偏倚与不确定性 | 按任务检查选择、混杂、缺失、报告偏倚及不确定性；当前材料能确认哪些，哪些未报告或未核？ |
| 稳健性与外推 | 是否有重复、消融、负例或外部条件检验？更换用户、环境、任务或装置后有哪些未经检验的依赖？ |
| 复现条件 | 代码、数据、配置和设备能否连回论文，哪些只是公开宣称、哪些已查看或运行？ |

每个重要判断给出原文依据、影响和未决项。材料未报告与已发现设计缺陷分开；只有元数据或摘要时标明不能完成的评价，不将访问困难记成低质量。领域专用偏倚工具只在研究单位和任务匹配时使用；不按期刊声望、引文数、收费状态或任意总分替代评价。

需要判断整组证据时，按具体结果或比较关联独立研究及其报告，说明重复样本、偏倚、冲突、缺失和适用条件怎样影响综合判断。共同作者或方法谱系本身不证明样本重复；跨研究同时变化的参与者、设备、训练量等条件未被控制时，结果差异只能支持观察到的比较，不能全归因于某一个改动。单篇报告完整性、研究偏倚风险和证据体确定性分别处理；不把来源数或单篇评分相加成整体可信度。GRADE 等工具仅在任务适合且可取得对应版本依据时使用，不普遍套到工程论文。

输出应能指出“哪项证据支持哪条主张、哪种替代解释未被排除、什么发现会改变判断”。

## 追问驱动的研究与地图更新

适用于已有地图、讨论中的问题变更或多轮研究。

1. 将追问关联到已有问题、主张和对象；先合并同义问题，保留新增条件。已有材料足够时直接回答。
2. 对尚未回答的部分选择互补取证入口。用户种子与引用链用于扩展，另保留不依赖同一种子的发现路径；重要新分支先记录，不必立即改变判断。
3. 每轮返回新增发现及来源、受影响的主张和未决问题。新问题按发现价值、区分解释的能力和成本选取，不按固定递归层数穷尽。
4. 新信息先归入合适对象或多标签，再判断是否需新增关系或重构分类。重要调整沿用主正文的框架变更记录；不为新增一条材料重做整张地图。
5. 讨论停滞时检查遗漏视角、反例或过于同质的来源。多个角色的赞同不是独立证据；需要新事实时回到材料，不能只让角色轮流发挥。

采用适合本题的关系结构，不强制树状地图、专家人数、轮数或来源数量。

## 从片段到有条件的判断

适用于深读、指标比较、争议核验和重要推荐。

先明确正在核验的主张及条件，再收集能回答它的原文片段或准确位置。将原文、针对问题的解释和最终判断区分开；必要时回读片段前后、方法和补充材料。摘要不足以核验时保留缺口。

按 [记录与表达](records-and-views.md) 检查身份、位置、主张支持与适用条件；把支持、反对、证据不足及条件不一致分别处理。追溯同一实验或数据的派生报道，保留有根据的争议，不将引用条数、相关度或 agent 投票转成置信度。

先对齐研究单位：一项研究的预印本、论文、仓库和博客可以是多份记录，不能自动算作多次独立验证。缺少指标、样本或实现细节时标明未报告；新材料提出的问题可留在比较字段之外。领域质量检查依研究类型选择；系统综述所需的筛选与排除记录仅在相应任务中展开。

草稿内的一致性检查、文献身份查询、原文支持核验、独立取证及实际运行分别报告。外部项目中名为 `fact-check` 的模块不因此获得独立核验地位。

## 按理解状态共读

适用于用户明确希望入门、逐步学习，或指出某个机制没看懂。

利用已知背景与本轮问题选择起点；只追问会影响解释的知识缺口。围绕一个关键机制给出输入输出、直观例子和必要技术细节，先补它所依赖的概念。共读时明确哪些是原文主张、通用背景、我们的推断或批评。

需要检查理解时，提出能区分关键解释的问题，例如改变一个条件后会发生什么，并根据回答补讲。用户要完整概览或跳过练习时沿其要求交付；短问答不强制启动完整教学阶梯。理解状态只记已观察到的表现，不能据此修改来源可靠性；需要长期保存时沿用本次写入范围。

## 条件决策与最小实验

适用于选路线、确定研究问题或准备高投入实验。

列清已确认的固定约束、可调参数及影响选择但未确认的权重。优先找出一旦不成立就会使路线失效的依赖；在关键分叉写明条件、现有依据及哪种新结果会改变路线。

能通过小规模取证或实验区分的，给出假设、对照、变量、可观察指标和否定条件，并解释它将排除哪个解释。阈值来自用户目标、已有基线或明确的设计选择，不能冒充文献结论或团队验收要求。无法消除的价值取舍由用户决定；当前只做探索时保留候选与未决问题即可。

进入实际实验前保留预测、主要指标和否定条件的当时版本；首次运行后的变更带日期与理由追加，原预测继续可见。探索性调整允许发生，但结果出现后的标准不能改写成事前标准。仅提出实验建议时保持计划状态，不声称已执行或已完成预测检验。

## 中断恢复与来源变更

适用于跨会话研究、多人协作或来源更新。先读取现有接续状态，与实际产物和证据核对，再从未完成或受影响的部分继续。记录缺失产物、失效链接和工具失败；保留可用的本地证据及版本，不能因在线链接失效就抹掉历史依据，也不能把旧版本当成当前状态。

稳定来源 ID 供报告与视图共用；合并 worker 的局部引用时建立映射。必要时用已授权的本地片段或原稿回查；尚未保存的材料按实际可获得性补取，仍不可获得则注明影响哪些结论。摘要无法恢复判断依据时，恢复状态尚未完成。
